## Batch Generation Strategy

### For Consistent Series
1. **Fix seed** for initial hero, then vary only camera angle
2. **Use same lighting** keywords across all shots
3. **Lock materials** description exactly
4. **Generate 4-8 variations** per angle, pick best
5. **Upscale** selected with 2x or 4x (Topaz, Magnific, or native)

## Quality Checklist Before Pipeline

- [ ] All three chambers visible with correct fill levels
- [ ] Correct colors: soap green, foam cyan/white, paste amber/white
- [ ] Matte white body, dark cap, chrome sensor ring
- [ ] Three LEDs (green, cyan, amber) + mode button "M"
- [ ] Three nozzles at bottom
- [ ] USB-C port on side (side views)
- [ ] Mounting bracket on back (mounted/lifestyle)
- [ ] "3·1" badge visible
- [ ] No extra fingers, text, watermarks
- [ ] Sharp focus on product, appropriate DOF
- [ ] Clean background (white seamless or contextual)
- [ ] sRGB color space, no color cast
- [ ] High resolution (≥2000px on long edge)

---

## Post-Processing Guidelines

1. **Color Calibration**: Match brand teal `#387763` exactly on badge/LEDs
2. **Background**: Pure white `#fafaf9` or clean cutoff for transparent BG
3. **Shadows**: Soft contact shadow only, no hard drops
4. **Sharpening**: Subtle high-pass (0.5-1px) for web
5. **Export**: PNG for archive, WebP 92q for web, AVIF 85q for modern
6. **Responsive**: Generate widths per SPECS in optimize script
