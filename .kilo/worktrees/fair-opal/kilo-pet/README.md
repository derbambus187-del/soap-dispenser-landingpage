# Kilo Pet

Kilo Pet runs as a VS Code panel instead of a separate website. To try it in VS Code, open the **Kilo Pet Extension** launch configuration and start debugging (F5). The pet appears in the bottom panel; drag it within the panel to move it, or tap it to open the Kilo Code chat.

The Kilo Pet MCP server provides generic task stages to the panel. It listens only on `127.0.0.1`; no status website or forwarded port is exposed.
